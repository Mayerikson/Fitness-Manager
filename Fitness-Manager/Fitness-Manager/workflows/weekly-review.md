# Weekly review workflow

1. Read only the current week's weight, nutrition, workout, and run records needed for the user's question.
2. Check data completeness and flag estimates or missing days.
3. Summarize adherence, average weight if at least 3 comparable readings exist, waist only if measured, strength trends for repeated exercises, and running tolerance.
4. Do not infer fat loss from a single weigh-in or muscle loss from one poor workout.
5. Decide: maintain, collect more data, or propose one limited adjustment.
6. State rationale, risks, confidence/uncertainty, approval needed, and review date.
