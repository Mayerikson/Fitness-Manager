# Release notes — 5.1.0-beta.4

## Escopo
Esta é uma atualização de especificação UX, sem implementação do PWA.

## Alterações
- Documentada a tela contextual de conclusão de treino.
- Definidos indicadores transparentes para duração e conclusão.
- Incluída comparação com sessão anterior somente quando houver dados comparáveis.
- Incluída opção de compartilhar resumo com dados sensíveis ocultos por padrão.
- Preservada navegação principal em Hoje, Academia e Evolução.

## Próximo passo
Implementar os wireframes em componentes funcionais do PWA e validar os fluxos com dados de teste, mantendo as regras de privacidade e precisão.
