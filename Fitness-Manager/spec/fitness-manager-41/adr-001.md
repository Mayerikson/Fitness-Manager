# ADR-001 — Local-first com backup externo criptografado

- Status: Proposto para beta pessoal.
- Contexto: dados pessoais de saude e treinamento devem permanecer independentes do modelo.
- Decisao: SQLite local como fonte oficial; backups locais; copia Google Drive somente em AES-GCM; Supabase adiado.
- Alternativas: plaintext Drive (rejeitada); Supabase imediato (complexidade/custo/conta); banco ativo criptografado (adiado por complexidade).
- Consequencias: sem passphrase, nao ha copia remota; perda da passphrase impede recuperar backup criptografado; Google Drive Desktop precisa confirmar sincronizacao.
