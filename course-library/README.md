# Private course library (local only)

This public repository intentionally excludes user-supplied and third-party course PDFs, spreadsheets, extracted text, and exercise tables. Do not commit those materials unless you have explicit redistribution rights.

For personal use, keep lawful copies outside the Git repository, for example:

- Windows: `%USERPROFILE%\.fitness-manager\course-library\`
- macOS/Linux: `~/.fitness-manager/course-library/`

Point your local agent instructions or private configuration to that directory. Keep original filenames and preserve the source file structure. When exercise prescriptions or video mappings matter, inspect the original source rather than relying on flattened text extraction.

Do not place personal measurements, health records, private profile JSON, databases, backups, or credentials in this directory if it is inside a synchronized or shared location.
