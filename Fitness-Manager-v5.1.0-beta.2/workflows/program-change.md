# Program-change workflow

1. Confirm current program, days/week, duration on program, attendance, and whether the plan is being followed.
2. Review exercise technique confidence, loads, reps, RIR/RPE, recovery, soreness, pain, sleep, and running load.
3. Compare with the exact source program in the user's private local course library, described in `course-library/README.md`. Inspect original workbooks for exact details; do not infer missing prescriptions.
4. Check schedule fit. Respect the user's currently stated resistance-training availability; do not recommend a higher-frequency split without explicit schedule change and justification.
5. Consider maintaining the current program if it remains effective. Change only for a documented reason (schedule, stagnation confirmed across multiple exposures, poor recovery, equipment, preference, or goal change).
6. Treat GVT, FST-7, Gironda 8x8, drop-set, rest-pause, strip-set, and maximal strength templates as advanced options, not automatic next steps.
7. Propose one change set, explain course-original vs adaptation, and ask user approval.
8. Record the decision and set an outcome review date.
